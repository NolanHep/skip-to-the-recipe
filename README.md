Just by entering a recipe link, Skip to the Recipe will retrieve the ingredients and instructions in a matter of seconds. Quickly locate only the portions you need without scrolling and without being inundated with advertisements. Use Skip to the Recipe too quickly and easily to collect the recipe's key components.

# Support/Issues

If you encounter any isuses or promblems, open a isuse [here](https://github.com/NolanHep/skip-to-the-recipe/issues), and I will respond soon as possable and assest you. If you know a bit about programming and encounter a bug, consister helping me fix it. See bellow for more infomation about contributing.

# Contributing

I would greatly appreciate it if you contributed fixes to bugs or your own ideas on features. If you don't know anything about programming, [submit an issue](https://github.com/NolanHep/skip-to-the-recipe/issues), and I or the contributors will look into bringing that idea alive. If you're contributing to the codebase, I ask that you follow some guidelines, such as not placing any type of middleware that grabs the user's private information and allows you to view and utilize it. If you do implement middleware that fetches the user's data and that is not harmful, please update the privacy policy. Have fun programming!
